FL STUDIO:
1. Set BPM to 136 and import MIDI from File -> Import -> MIDI file. Enable import of all tracks.
2. Each MIDI track is separated. Load the indicated WAV file on its corresponding Sampler channel.
3. For drum channels, use STEMS/ individual MIDIs with one note per trigger. Set each sampler root note to C5 (FL Studio) or transpose individual drum MIDI notes to the root of your sampler; GENERAL MIDI full file uses standard drum note numbers.
4. IMPORTANT: For melodic one-shots and 808s, verify original pitch/root note (usually C). Tune samplers so all notes are in F minor. Use Cut Itself on 808 and short volume release.
